## ✨ Key Features

*   **Real-Time Data Integration:** Fetches up-to-date cryptocurrency prices and market trends using a REST API.
*   **Offline Support:** Implemented a robust local caching system to ensure the app remains fully functional and displays the latest loaded data even without an active internet connection.
*   **Optimized Performance:** Smooth scrolling and UI animations maintaining a consistent 60 FPS.
*   **Clean Architecture:** Predictable state management and separation of business logic from the UI layer.

## 🛠 Tech Stack

*   **Framework:** [Flutter](https://flutter.dev/)
*   **Language:** Dart
*   **Networking:** [Dio](https://pub.dev/packages/dio) for efficient and reliable HTTP requests, timeouts, and interceptors.
*   **Local Storage:** [Hive](https://pub.dev/packages/hive) for lightweight, high-performance NoSQL local data caching.
